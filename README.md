# PDF 在线编辑器

以文档为核心的 PDF 在线编辑工具：**直接编辑原始文档上的文字与图片，也可以添加新文字、新图片和各类标注元素**。所有处理均在浏览器本地完成，文档不会上传到任何服务器。

## 技术栈

| 组件 | 技术 | 用途 |
|---|---|---|
| 文档渲染 | [pdf.js](https://github.com/mozilla/pdf.js) 3.11 | 页面渲染、原文文字提取（含 CMap 中文支持）、图片定位 |
| 写回导出 | [pdf-lib](https://github.com/Hopding/pdf-lib) 1.17 + @pdf-lib/fontkit | 将全部编辑写回 PDF，中文 TTF 子集化嵌入 |
| 前端 | 原生 ES Modules + DOM 覆盖层 | 零构建、零框架依赖，交互编辑层 |
| 存储 | IndexedDB | 最近文件、自动保存与断点续编 |
| 服务 | Node 原生 http（`server.js`） | 零依赖静态服务器 |

## 快速开始

```bash
npm install          # 安装 pdfjs-dist / pdf-lib / fontkit（构建期用）
npm start            # 启动服务，默认 http://localhost:8023（可 npm start -- 3000）
```

浏览器打开 <http://localhost:8023>，拖入 PDF 或点击「打开示例文档」。

首次部署后如需重新生成示例文档：`npm run make:sample`。

> 字体文件在搭建时从 Windows 字体目录复制/抽取到 `public/assets/fonts/`（宋体、微软雅黑为
> TTC 集合，经 `scripts/expand-fonts.mjs` 纯 Node 抽取为独立 TTF），屏幕显示与导出嵌入使用
> 同一份字体，保证所见即所得。扩充字体：`node scripts/expand-fonts.mjs` 后编辑 `fonts.json`。

## 功能总览

### 编辑原始内容（以文档为核心）
- **原文文字**：选择工具下点击任意原始文字即可选中，支持
  - ✏️ **编辑**：原位覆盖并进入编辑，**精细还原原始样式**——
    - 从 PDF 直接提取**原始内嵌字体程序**（FontFile2 流解码后注册为 Web 字体），显示与导出复用同一份字体，字形、字宽与原文完全一致（适用于保留 cmap 表的字体，如 Word/WPS/浏览器打印导出的文档）
    - 无 cmap 的 CID 子集自动回退到**同族内置字体**（按真实字体名映射，覆盖中西 19 族：SimSun→宋体、Microsoft YaHei→微软雅黑、Calibri→Calibri、Segoe UI→Segoe UI、Consolas→Consolas 等；字体名无法识别时按 pdf.js 泛型族兜底 sans→Arial、serif→Times、mono→Courier）
    - **宽度比例补偿（scaleX）**：原文若被水平压缩/加宽，编辑后的文字按 `原文字宽 / 自然字宽` 比例逐字还原
    - **逐项字距还原（adv）**：一行内字距不均匀时（如标题拉宽、局部紧排），按每个文本项各自的比例分别缩放——显示端逐段 span、导出端逐项逐字定位；文本被修改后自动降级为整体比例
    - 字号精确到 0.1pt；**字重识别**（Light/Medium/SemiBold/Bold/Black → CSS font-weight 数值，导出按 ≥600 选粗体文件、≥550 触发合成粗体）；**粗体/斜体**从字体名识别
    - **智能选字**：所选字体族缺字形时，导出自动换用全覆盖族（宋体 GBK 全覆盖优先）；西文字体族的显示栈追加黑体回退，保证显示与导出一致
    - 颜色自动采样（红字改完仍是红字）
    - 新输入字符不在原字体子集内时自动回退并提示
    - **中文合成粗体**：无粗体变体文件的字体族（黑体/宋体/楷体/仿宋/等线），导出时以双向微偏移叠绘模拟笔画加粗，与显示端 CSS 合成粗体一致（微软雅黑有独立粗体文件，无需合成）
  - 🗑 **删除**：涂白覆盖该段
  - ⧉ **复制**
- **原图**：自动检测 PDF 内嵌图片位置，点击后支持
  - 🗑 **删除**、🔄 **替换**（上传新图填入原图区域）
  - ✂️ **剪切**：高清栅格化为可自由移动/缩放/旋转的新图片元素
  - ⬇ **提取**：导出为 PNG
- **智能文字重建**：任何涂白/删图操作覆盖到的原文文字会自动按原位置、原字号、采样颜色重绘，文档保持可读

### 添加新元素
文字（**19 种字体**：黑体/宋体/微软雅黑/楷体/仿宋/等线 + Arial/Times/Courier/Calibri/Cambria/Consolas/Georgia/Verdana/Tahoma/Trebuchet/Segoe UI/Impact 等，字号、颜色、字重、粗斜体、对齐、行距）、图片（拖放/粘贴上传）、矩形、椭圆、直线、箭头、高亮、涂白、自由画笔（可当签名用）。

**编辑文字时，顶部属性栏实时生效**：切换字体、调整字号、字重/粗斜体、对齐方式都会即时应用到正在输入的文字，且 B/I/对齐按钮不会打断输入焦点。多数西文字族带完整变体（常规/粗/斜/粗斜/细），导出按字重与斜体自动选用对应真实字体文件。

所有元素支持：拖动、8 向缩放（含旋转态）、旋转（15° 步进/90° 吸附）、层级调整、复制、方向键微调。

### 文档管理
- 页面缩略图侧栏，页级操作：插入空白页、删除页
- 缩放 25%–400%（Ctrl+滚轮以指针为中心、Ctrl+0 适应宽度）
- 撤销/重做（快照式，80 步）
- IndexedDB 自动保存 + 「最近文件」断点续编（约 0.9 秒防抖）
- 导出：pdf-lib 生成全新 PDF，中文字体子集化嵌入，中西文混排自动分段选字体

### 快捷键
`V/T/I/R/O/L/A/H/W/P` 切换工具 · `Ctrl+Z / Ctrl+Y` 撤销重做 · `Ctrl+D` 复制元素 · `Ctrl+C/V` 元素复制粘贴 · `Del` 删除 · `方向键`（Shift×10）微调 · `Ctrl+O` 打开 · `Ctrl+S` 导出 · `Ctrl+=/-/0` 缩放 · `Esc` 取消/回到选择 · 双击文字编辑，双击原文快速改写 · 拖图片文件到页面直接放置 · `Ctrl+V` 粘贴图片

## 架构说明

```
public/
  js/
    state.js        全局状态 + 事件总线 + 撤销重做 + 自动保存调度
    pdfview.js      pdf.js 渲染管理；原文层（文字运行合并、图片热区检测）；
                    区域栅格化；文字颜色采样；rAF 看门狗兜底
    elements.js     元素模型与 DOM 渲染；涂白后文字重建
    interactions.js 工具状态机：绘制/拖动/缩放/旋转/文字编辑/原文操作
    handles.js      选择手柄层
    propsbar.js     上下文属性栏（随工具与选中元素变化）
    exporter.js     pdf-lib 导出（字体子集、混排分段、旋转坐标换算）
    fonts.js        字体清单（@font-face 显示 + 导出嵌入共用）
    store.js        IndexedDB（meta/files 双仓）
    ui.js           工具栏/缩略图/欢迎页/弹窗/拖放/缩放
```

**坐标体系**：所有编辑数据以「页面 pt、原点左上、y 向下」存储（与 CSS 显示一致），
渲染时按缩放比例布局；导出时经 pdf.js viewport `convertToPdfPoint` 换算回 PDF 用户空间，
天然支持带 /Rotate 的页面。旋转元素通过「绕中心旋转的锚点 + 等效旋转角」写回。

**已知限制**（与主流网页 PDF 编辑器一致）：
- 原文编辑采用「覆盖重写」而非内容流改写，段落级重排（如改变行宽）不支持
- 带密码的 PDF 可打开查看编辑，但导出可能不完整（会提示确认）
- 「剪切」得到的图片是栅格快照，其中已包含区域内的文字（该文字不再重复重建）

## 调试入口

浏览器控制台可访问 `window.__app`（state / pdfview / elements / exporter / ui），供自动化测试与排查。
